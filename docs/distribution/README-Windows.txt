GodSense - candidato local para Windows x64

Extrae toda la carpeta y ejecuta godsense.exe. Conserva las DLL y la carpeta
data junto al ejecutable. No necesita Flutter, Python ni Node instalados.

Abre League of Legends para conectar tu cuenta automaticamente. En Mapa,
calibra el minimapa con una partida visible. Revisa esa calibracion cuando
cambies la pantalla, resolucion o tamano del minimapa.

Los modelos de voz se instalan desde Ajustes. El chat con IA requiere un
proveedor y un modelo configurados. Las funciones de IA son opcionales.

Puedes exportar o borrar el historial desde Ajustes. No se incluyen partidas,
credenciales, modelos de voz ni datos personales en este paquete.

Este paquete es un candidato local sin firma digital ni actualizador propio.
La distribucion por Microsoft Store requiere su paquete e identidad oficiales.
GodSense es un proyecto independiente, no un producto oficial de Riot Games.

build-manifest.json identifica el codigo fuente y las sumas SHA256 de archivos.
